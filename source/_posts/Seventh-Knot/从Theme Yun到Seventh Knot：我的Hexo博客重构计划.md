# 从 Theme Yun 到 Seventh Knot：我的 Hexo 博客重构计划

> Seventh Knot 不是一次简单的换色，而是把一个“能写文章的 Hexo 站点”重新整理成具有独立视觉、交互节奏和内容体系的个人项目。

<!-- more -->

## 为什么要重构

Theme Yun 的结构清晰、功能完整，也是我最早选择它的原因。但随着文章、页面和自定义组件不断增加，原来的站点逐渐出现三个问题：桌面端有个性，移动端却缺少完整体验；首页只能承担文章列表功能，无法表达站点气质；自定义代码散落在配置、模板和样式中，很难继续维护。

我希望新版本同时满足以下目标：

1. 保留 Hexo 的写作与静态生成能力；
2. 保留 Theme Yun 成熟的文章页、分类、标签和评论结构；
3. 建立独立的首页叙事，而不是只修改主题颜色；
4. 让移动端成为正式设计对象；
5. 让修改后的程序可以作为一个项目继续维护。

## 先划分改造边界

我没有直接修改所有上游文件，而是把代码分成三层：

```text
source/css/custom_theme.css       视觉覆盖与响应式规则
source/js/                        首页、移动导航和网页宠物逻辑
themes/yun/layout/                必须改变页面结构时修改 Pug
```

能用 CSS 完成的效果不修改模板；需要新增语义结构时才调整 Pug；需要状态切换和事件监听时再加入 JavaScript。这样做虽然不能完全避免升级冲突，但能让问题集中在少数文件里。

## 重构路线

整个过程被拆成五个阶段：

### 第一阶段：建立视觉基线

先统一背景、面板、强调色、边框和阴影。Seventh Knot 使用黄色、蓝色和近黑色作为核心颜色，并通过 CSS 变量统一管理。

### 第二阶段：重做首页

保留 Yun 原本的文字开场动画，在它之后加入加载阶段，再显示个人主页。首页由“文字标题 → 系统连接 → 个人节点”三种状态组成，但在用户感知上仍是两段式叙事。

### 第三阶段：完善内容入口

首页文章卡片不再只有标题和元信息，而是直接展示正文片段；同时重新整理分类、标签、代理人列表和社交入口。

### 第四阶段：移动端适配

针对小屏幕重写导航展开方式、首页间距、卡片宽度、触控区域和安全边距，避免把桌面布局简单压缩。

### 第五阶段：项目化

把项目命名为 **Seventh Knot · 第七绳结**，补充 README、版本号、仓库信息与版权说明，并将完整版本合入 GitHub 的 `main` 分支。

## 最重要的取舍

重构过程中最重要的决定，是不把 Theme Yun 完全隐藏。文章页、归档、标签等成熟能力依然来自上游主题；Seventh Knot 主要负责首页叙事、视觉语言和个性化交互。

因此，它更准确的定位是：

> 一个基于 Hexo 与 Theme Yun 深度二次开发、但具有独立设计语言的个人博客项目。

## 阶段性结果

现在的 Seventh Knot 已经拥有两段式首页、Inter-Knot 风格界面、邦布加载动画、云雾过渡、网页宠物、文章局部预览和完整的移动端布局。更重要的是，这些功能不再只是零散补丁，而是围绕同一个项目名称和设计目标组织起来。

后续文章将分别记录首页动画、视觉系统、邦布与宠物、移动端适配、文章预览以及 GitHub 项目迁移的具体实现。
