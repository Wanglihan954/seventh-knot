## DRGBT 动态 RGB-T 跟踪：任务、数据、方法与研究版图

> **摘要｜本文结论**
> DRGBT（Dynamic RGB-T Tracking）不是“采用动态权重的 RGBT 跟踪”，而是指**可用传感模态和观察平台会在跟踪过程中发生变化**的单目标跟踪。严格按这一定义，截至 2026 年 10 月，公开研究仍处于非常早期：DRGBT603/CMRL 首次系统定义任务并给出基准与专用方法，DRGBT-1K 随后用 1,045 条全真实跨平台序列补足规模和真实性。缺失模态、未配准 RGBT、跨视角/UAV 跟踪和传统 RGBT 融合构成其四条最重要的邻近技术线，但它们各自只覆盖 DRGBT 的部分困难，不能直接等同于 DRGBT。

### 0. 先把容易混淆的术语分开

“动态 RGBT”至少有三种完全不同的用法：

| 术语中的“动态” | 实际含义 | 是否属于本文的 DRGBT |
|---|---|:---:|
| 动态融合/动态权重 | 两种模态一直存在，只是模型按质量调整权重 | 否 |
| 动态模板/时序建模 | 用历史帧更新目标模板 | 否 |
| Dynamic RGBT Tracking | 模态状态和/或观察平台随时间变化 | **是** |

因此，MFGNet、TATrack、DDFNet 等名称中虽然有 Dynamic/Temporal，它们主要仍在固定平台、完整双模态基准上研究内容自适应融合或模板更新；它们是重要基础，但不是严格意义上的 DRGBT 专用方法。

## 1. 从 RGBT 到 DRGBT：任务为何发生变化？

### 1.1 传统 RGBT 单目标跟踪

传统 RGBT 跟踪在首帧给定目标框，之后接收同步且通常已经配准的 RGB–TIR 图像对：

$$\hat b_t=f_\theta\!\left( I_t^{R}, I_t^{T}, I_1^{R}, I_1^{T}, b_1 \right),$$

其中 $I_t^{R}$ 与 $I_t^{T}$ 在整个序列中始终存在，成像设备和观察视角也基本固定。研究重点是如何利用 RGB 的纹理/颜色信息与 TIR 的热辐射信息进行互补。

### 1.2 DRGBT 的输入不再固定

DRGBT 在时间 $t$ 的观测应写成：

$$O_t=\left\{I_t^m\mid m\in\mathcal M_t\right\}, \quad \mathcal M_t\subseteq\{R,T\}, \quad p_t\in\mathcal P,$$

其中：

- $\mathcal M_t$ 是当前可用模态集合，可为 RGB-only、TIR-only 或 RGBT；
- $p_t$ 是当前观察平台，例如 ground 或 UAV；
- $\mathcal M_t$ 与 $p_t$ 都可能随时间变化。

跟踪目标仍然是同一个物理对象，但观测生成机制发生了变化：

$$\hat b_t=f_\theta\left(O_t,p_t,\mathcal H_{t-1},b_1\right),$$

其中 $\mathcal H_{t-1}$ 是历史状态、模板或记忆。模型不仅要定位目标，还要判断当前观测是否可信、是否发生模态/平台切换，以及是否应更新长期表征。

### 1.3 一个真实的 DRGBT 过程

```text
地面 RGB-T 相机发现行人
        ↓ RGB+TIR
行人进入暗区，RGB 基本失效
        ↓ TIR-only
目标离开地面相机视野，由无人机接管
        ↓ 平台切换 + 俯视小目标 + 尺度突变
无人机热红外链路暂时中断
        ↓ UAV RGB-only
链路恢复
        ↓ UAV RGB+TIR
```

这个例子同时包含模态可用性变化、模态质量变化、跨平台交接、跨视角外观不连续、小目标和通信异常。传统“双流特征融合”只解决其中一部分。

### 1.4 三种官方评测子任务

| 子任务 | 模态变化 | 平台变化 | 主要考察能力 |
|---|:---:|:---:|---|
| MVO（Modality Variation Only） | ✓ | ✗ | 缺失模态适应、统一输入表征 |
| PVO（Platform Variation Only） | ✗ | ✓ | 跨视角身份保持、全局重定位 |
| CV（Combined Variation） | ✓ | ✓ | 模态与平台联合变化下的整体鲁棒性 |

DRGBT-1K 上 MVO 显著容易于 PVO，CV 最难。这说明当前真正的瓶颈不是简单补全缺失模态，而是平台切换造成的分布断裂。

## 2. DRGBT 到底难在哪里？

### 2.1 模态存在性与模态质量是两件事

应区分：

- **Availability**：某个模态是否存在；
- **Validity/Quality**：它虽然存在，但是否提供有效信息。

例如夜间 RGB 帧仍然存在，却可能几乎全黑；热交叉时 TIR 仍存在，却无法区分目标与背景。若模型只使用二值 missing mask，就无法处理“存在但无效”的模态。

更完整的状态可写为：

$$s_t^m=(a_t^m,q_t^m), \quad a_t^m\in\{0,1\},\ q_t^m\in[0,1],$$

其中 $a_t^m$ 表示可用性，$q_t^m$ 表示质量或置信度。

### 2.2 平台切换带来的是非平稳观测

地面与无人机观察同一目标时，变化常同时发生：

- 视角由侧视变为俯视；
- 目标尺度和长宽比突变；
- 背景语义与干扰物改变；
- 相机运动模型改变；
- 分辨率、曝光、热成像动态范围改变；
- 目标在新平台画面中的位置可能没有局部连续性。

传统局部搜索依赖假设 $b_t$ 接近 $b_{t-1}$。平台切换后这个假设可能立即失效，所以 DRGBT 需要“局部连续跟踪 + 事件触发的全局重定位”两种工作模式。

### 2.3 目标表征既要不变，又不能丢掉互补信息

理想表征需要同时满足：

$$z_t=z_t^{\mathrm{shared}}\oplus z_t^{\mathrm{specific}},$$

- $z^{\mathrm{shared}}$：跨模态、跨平台仍稳定的目标身份信息；
- $z^{\mathrm{specific}}$：RGB 纹理颜色、TIR 热响应、平台视角等条件特异线索。

只学特异特征会过拟合某一模态/平台；只追求完全不变，则可能把真正有区分力的互补线索一起抹掉。DRGBT-1K 上 CMRL 在 PVO/CV 有优势但总体并非最佳，正说明“不变性”不是全部答案。

### 2.4 模板更新在切换点最危险

平台切换后的第一批帧往往尺度小、位置不确定、外观差异最大。如果立即用低质量预测更新模板，错误会被写入长期记忆；如果完全不更新，又无法适应新视角。因此模板管理应显式区分：

- 不可覆盖的初始身份锚点；
- 短期运动模板；
- 平台/模态特异模板；
- 经质量门控后写入的长期模板。

### 2.5 空间未配准会与动态变化耦合

真实设备中的 RGB 与 TIR 存在平移、尺度、视差和视场差异。固定平台下，错位已经会破坏逐像素融合；平台切换后，错位分布本身还会改变。因此 DRGBT 的完整难度并非简单相加：

$$\text{DRGBT 难度} \neq \text{Missing} + \text{Cross-view} + \text{Unaligned},$$

而是三者在切换点相互放大。

## 3. 核心研究时间线：严格意义上的 DRGBT 文献并不多

> **说明｜检索边界**
> 截至 2026-10-03，以论文标题、摘要、数据集和实验协议是否同时涉及“模态随时间变化”和“跨平台切换”为判断标准，严格的公开 DRGBT 主线目前主要由以下两项工作构成。其他工作放在第 5 节作为邻近研究，而不冒充 DRGBT 专用研究。

### 3.1 2026：DRGBT603 + CMRL，首次系统定义任务

**论文**：*Causality-Based Modality- and Platform-Invariant Representation Learning for Dynamic RGBT Tracking and a Benchmark*，IEEE TIP 2026，35:3141–3156，DOI: 10.1109/TIP.2026.3674367。

这项工作完成两件奠基性的事：

1. 定义动态 RGBT 跟踪：跟踪过程中可用模态和观察平台发生变化；
2. 构建 DRGBT603，并提出因果式模态与平台不变表征方法 CMRL。

#### CMRL 的核心假设

作者把图像因素分为：

- **因果因素**：与目标身份和定位真正相关的信息；
- **非因果因素**：模态、平台等环境因素带来的外观变化。

目标是通过干预模拟模态/平台变化，迫使模型保留目标相关因素，而不是记住特定传感器或视角的统计相关性。

#### 两个主要模块

| 模块 | 解决的问题 | 核心做法 |
|---|---|---|
| Causal Consistency Encoder | 模态切换 | 引入 intervener 建模特征不确定性并模拟模态变化，学习模态不变特征 |
| Platform-independent Global Searcher | 平台切换、位置跳变 | 在平台切换时进行全局重定位，并通过干预抑制平台特异干扰 |

CMRL 的重要价值是第一次把 DRGBT 问题拆成“模态稳定表征”和“平台切换重定位”两个机制，而不是继续把所有问题塞进一个融合模块。

#### DRGBT603

| 项目 | 数值 |
|---|---:|
| 序列数 | 603 |
| RGBT 帧对 | 约 1.49M |
| 目标类别 | 29 |
| 挑战属性 | 12 |
| 真实跨平台序列 | 203 |
| 合成跨平台序列 | 400 |

它首次提供可训练评测的 DRGBT 基准，但 2/3 的跨平台序列为合成构造，成为后续 DRGBT-1K 要解决的主要限制。

### 3.2 2026：DRGBT-1K，把基准推进到全真实大规模阶段

**论文**：*DRGBT-1K: A Large-scale High-quality Benchmark for Dynamic RGBT Tracking*，arXiv:2607.19772v1。

![DRGBT-1K 与现有 RGBT/DRGBT 基准对比](https://cdn.jsdelivr.net/gh/Wanglihan954/Picture-bed@img/img/rgbt-notes/DRGBT-1K/tab1-dataset-comparison.png)

DRGBT-1K 不再以合成跨平台视频扩充数量，而是使用无人机和地面/手持 RGBT 设备真实协同拍摄：

| 项目 | DRGBT-1K |
|---|---:|
| 序列 | 1,045 |
| 帧对 | 约 795K |
| 目标框 | 约 799K |
| 类别 | 24 |
| 场景 | 超过 15 |
| 属性 | 15 |
| MVO / PVO / CV | 209 / 209 / 627 |
| 真实 / 合成跨平台 | 1,045 / 0 |
| Train / Test | 800 / 245 |

它还提供：

- 逐帧 RGB-only/TIR-only/RGBT 模态标签；
- 地面/UAV 平台与切换标签；
- Unaligned DRGBT-1K；
- RGB-only 的 UGVT-1K；
- 在线评测与 20 个代表性基线结果。

DRGBT-1K 的定位不是提出新跟踪器，而是把 DRGBT 从“任务概念 + 初始基准”推进到更可靠的全真实研究平台。详细构造见 [DRGBT-1K](/posts/147fa31e/)。

### 3.3 当前核心研究状态

截至检索日期，DRGBT-1K 的官方基准把方法分为三类：

- 常规 RGBT 跟踪器：16 个；
- modality-missing RGBT 跟踪器：3 个；
- 专用 DRGBT 跟踪器：**1 个（CMRL）**。

这比任何 SOTA 排名都更能说明领域现状：数据集已经出现，但专用方法研究还远未饱和。

## 4. 两个 DRGBT 数据集如何选择？

| 维度 | DRGBT603 | DRGBT-1K |
|---|---:|---:|
| 首要意义 | 首次定义任务并提供基准 | 首个大规模全真实 DRGBT 基准 |
| 序列数 | 603 | 1,045 |
| 总帧数 | 1.49M | 795K |
| 真实跨平台 | 203 | 1,045 |
| 合成跨平台 | 400 | 0 |
| 类别/属性 | 29 / 12 | 24 / 15 |
| 动态细分 | 有动态设定 | 明确 MVO/PVO/CV |
| 未配准版本 | 未作为主贡献提供 | 提供 |
| UAV–Ground RGB 派生任务 | 无 | UGVT-1K |

建议：

- 用 DRGBT603 与 CMRL 对齐早期研究和原始任务定义；
- 用 DRGBT-1K 作为主要结论依据，特别是跨平台、小目标和未配准研究；
- 若声称解决真实跨平台问题，不能只在 DRGBT603 的合成部分上报告结果；
- 最好同时报告 MVO、PVO、CV，避免总体分数掩盖模型只擅长模态缺失。

## 5. 四条邻近研究线：它们如何汇入 DRGBT？

### 5.1 缺失模态 RGBT：解决 $\mathcal M_t$ 变化

#### IPT：Invertible Prompt Learning

*Modality-missing RGBT Tracking: Invertible Prompt Learning and High-quality Benchmarks* 首次系统构建多种缺失模态设置。其核心思想是用可用模态生成缺失模态的提示，同时通过可逆重建约束减少跨模态生成中的语义失真和信息丢失。

它对 DRGBT 的贡献是提供“一个模态突然不可用时如何保持统一双模态接口”的基础方案；局限是它没有解决地面—无人机平台切换。

#### TMKD：时序/知识蒸馏路线

TMKD 被 DRGBT-1K 作为 modality-missing 基线评测，并在总体 SR 上排名靠前。此类方法利用完整模态教师或跨时序知识，把多模态信息迁移到缺失输入状态。其风险是教师知识可能仍绑定固定平台分布。

#### SCDT：条件去噪统一完整与缺失模态

SCDT（CVPR 2026）不直接生成缺失图像，而是在特征空间利用短期历史和描述模态演化的长期上下文，条件式去噪可用模态特征；噪声调制机制使同一模型在完整和缺失输入下工作。

对 DRGBT 而言，SCDT 的长期模态演化建模比逐帧补全更合理，但仍需要与平台切换检测和全局重定位结合。

#### MV-RGBT：从 missing 扩展到 invalid

*Revisiting RGBT Tracking Benchmarks From the Perspective of Modality Validity* 构建 MV-RGBT，关注极端照明与热截断条件下“模态存在但失效”。它提醒 DRGBT：模态标签不能只做三值枚举，还需要连续质量估计。

### 5.2 未配准 RGBT：解决跨模态几何不一致

#### LasHeR unaligned 版本

LasHeR 在大规模已配准 RGBT 基准之外发布未配准版本，较早推动 alignment-free tracking，但仍是固定平台任务。

#### AMNet 等早期对齐方法

这一类方法在特征融合前估计跨模态偏移或用可变形机制建立对应。其常见隐含假设是偏移较平滑、搜索目标仍位于两个模态的相近区域。

#### PMATrack + MUART244

PMATrack（CVPR 2026）把对齐参数估计拆成中心偏移、尺度变换和全局精修三个阶段，并由难度感知路由器选择不同对齐专家。它比一次性联合回归所有参数更适合不同错位程度，并同时控制计算量。

对 DRGBT 的直接启示是：对齐不应是固定预处理，而应在每个平台/切换阶段重新估计；但 PMATrack 本身仍不解决模态缺失或平台交接。

#### Unaligned DRGBT-1K

DRGBT-1K 以图像对角线 $D$ 归一化偏移，把 TIR 相对 RGB 的空间偏差限制在 $[0.01D,0.17D]$，并加入多种时间变化和缩放模式。这是目前最直接把未配准问题接入 DRGBT 的评测入口。

### 5.3 跨视角与 UAV–Ground 跟踪：解决 $p_t$ 变化

传统 UAV 跟踪关注单个平台内的快速运动、小目标和相机运动；跨摄像头跟踪/重识别关注不同相机之间身份匹配，但通常不要求逐帧连续输出目标框。DRGBT 位于二者之间：既要跨视角保持身份，又要完成连续 SOT 定位。

UGVT-1K 去除热红外后保留 1,045 条地面—无人机 RGB 轨迹，可用于单独研究平台切换。一个合理的研究顺序是：

1. 先在 UGVT-1K 解决跨平台 RGB 跟踪；
2. 再在 DRGBT-1K 加入模态可用性变化；
3. 最后在 Unaligned DRGBT-1K 加入跨模态错位。

### 5.4 常规 RGBT：提供互补融合和时序建模能力

DRGBT-1K 评测的常规/通用基线包括：OSTrack、TBSI、TATrack、BAT、PURA、SDSTrack、MMLoRAT、CKD、AINet、STTrack、CAFormer、FMTrack、QSTNet、MRTTrack、UATrack、GOLA。

这些方法覆盖几条成熟技术路线：

| 路线 | 代表能力 | 对 DRGBT 有用之处 | 仍缺少什么 |
|---|---|---|---|
| 双流交互/融合 | 跨模态互补 | 正常 RGBT 段的强表征 | 无法自然处理输入分支消失 |
| Prompt/Adapter | 参数高效适配 | 可按模态状态条件化模型 | 通常没有平台切换机制 |
| 共享—特异分解 | 保留共同与模态专有信息 | 缓解纯不变表征的信息损失 | 需要跨平台解耦和状态管理 |
| 动态模板/时序记忆 | 适应外观变化 | 提供切换后的在线适应 | 切换点容易污染模板 |
| 质量感知融合 | 抑制低质量模态 | 处理 invalid modality | 不等于 missing，也不等于 cross-platform |
| 统一多模态跟踪 | 单模型处理不同传感输入 | 为任意模态接口提供基础 | 通常在数据集级切换任务，而非序列内切换 |

它们在 DRGBT-1K 上可以是强基线，但若训练目标从未见过平台切换，好的平均结果不能证明已经解决 DRGBT。

## 6. 现有专用方法 CMRL 应如何理解？

### 6.1 因果表述的直觉

可把观测写为：

$$X=g(C,S_m,S_p,\epsilon),$$

其中 $C$ 是目标相关因素，$S_m$ 是模态因素，$S_p$ 是平台因素。跟踪输出应主要由 $C$ 决定，而不能依赖训练集中 $S_m,S_p$ 与目标位置的偶然相关性。

CMRL 的 intervener 本质上通过模拟环境变化，要求表征在干预模态/平台因素后仍维持目标判断。这更接近域泛化，而不等同于严格从观测数据识别真实因果图。阅读论文时应把“causality-based”理解为一种**干预式不变学习归纳偏置**，不要把它误解为已经证明了传感器、平台和目标之间的真实因果关系。

### 6.2 为什么需要全局搜索？

固定平台 SOT 通常围绕上一帧位置裁剪搜索区域。平台切换后，新视图中的目标位置可能与旧坐标毫无局部对应：

$$\lVert c_t-c_{t-1}\rVert \gg r_{\text{local search}}.$$

因此 CMRL 在平台切换时启用 platform-independent global searcher。它解决的是“目标可能根本不在原局部窗口内”，这是单纯增强特征融合无法解决的结构性问题。

### 6.3 为什么它还不是终点？

- 不变性可能压制模态互补信息；
- 平台切换标签在实际系统中未必提前给出，需要在线检测；
- 全局搜索计算开销更高，也易受相似目标干扰；
- DRGBT603 大量合成序列可能让模型学习到合成切换规律；
- 对自然未配准、异步和通信延迟的处理仍不足。

DRGBT-1K 上 CMRL 的总体成绩不是最高，但在 PVO/CV 和部分退化属性上显示优势，说明其问题分解是有效的，具体实现仍有很大提升空间。

## 7. 如何公平评测 DRGBT 方法？

### 7.1 基本协议

两套基准主要采用 OPE：只在初始帧给出目标框，跟踪器不能在失败后用真值重启。常用指标：

- PR：中心误差在 20 像素内的比例；
- NPR：按目标尺寸归一化的中心精度；
- SR：IoU 成功率曲线 AUC。

对于跨平台小目标，NPR 和 SR 通常比固定 20 像素 PR 更可靠，因为同样的像素误差对 15 像素目标和 150 像素目标意义不同。

### 7.2 必须拆分报告的结果

至少报告：

| 层级 | 必需切片 |
|---|---|
| 动态类型 | MVO、PVO、CV |
| 平台方向 | Ground→UAV、UAV→Ground |
| 模态状态 | RGB-only、TIR-only、RGBT，以及切换前后窗口 |
| 关键属性 | SO、LR、SV、ARC、BC、LI、TC、FL |
| 对齐条件 | aligned、unaligned |
| 时间位置 | 切换前、切换后 1–10/11–50/50+ 帧 |

只报整体 PR/SR 会掩盖一个常见现象：方法可能在占比高的正常段很好，却在真正关键的交接点立即失败。

### 7.3 建议增加的 DRGBT 专用指标

现有 OPE 指标没有直接度量“交接恢复能力”。建议加入：

#### 切换冲击（Transition Drop）

$$\Delta_{tr}=S_{pre}-S_{post},$$

比较切换前窗口与切换后窗口的成功率。

#### 恢复时间（Time to Recover）

从切换帧开始，直到连续 $k$ 帧 IoU 超过阈值所需的帧数；从未恢复则记为失败。

#### 身份保持率

在存在相似目标时，切换后是否仍跟随同一物理目标，而不是只看某一帧的几何重叠。

#### 模态退化曲线

按可用模态连续缺失长度、质量和错位幅度分桶，绘制性能下降曲线，而非只比较一个固定缺失比例。

### 7.4 防止数据泄漏

- 真实跨平台同一目标的两个视图不应分到训练和测试两侧；
- 同一原始视频裁剪出的片段应作为一个 group 划分；
- 合成未配准扰动不能让训练与测试共享同一随机轨迹；
- 使用平台/模态标签作为输入时，应明确实际部署能否获得这些标签。

## 8. DRGBT-1K 基线揭示的现状

DRGBT-1K 对 20 个方法的统一评测中，GOLA 总体最佳，为 51.18 PR / 46.42 NPR / 38.01 SR；专用 DRGBT 方法 CMRL 为 43.03 / 38.48 / 31.82。

![DRGBT-1K 总体基线结果](https://cdn.jsdelivr.net/gh/Wanglihan954/Picture-bed@0df6e1a/img/rgbt-notes/DRGBT-1K/tab4-overall-results-clean.png)

但总体排名不能简单得出“专用方法没有用”：属性和子集评测显示 CMRL 在平台切换相关的 PVO/CV 上更有竞争力，而强常规模型依靠更好的骨干、融合或训练策略获得较高平均值。更准确的结论是：

1. 强基础跟踪能力仍然决定性能下限；
2. 平台不变机制确实有效，但不能牺牲模态互补与精细定位；
3. 当前还没有方法同时解决完整输入、缺失模态、平台切换和空间未配准。

三类动态子集的最佳结果大致从 MVO 的 78.72/57.24，降到 PVO 的 42.90/35.96，再降到 CV 的 34.61/28.46（PR/SR）。这几乎把未来研究优先级写得很清楚：**跨平台交接 > 单纯缺失模态**。

## 9. 一个完整 DRGBT 系统应该包含哪些模块？

```text
输入适配层
  ├─ 读取任意 RGB/TIR 组合
  ├─ 模态存在性 mask
  └─ 模态质量/有效性估计
          ↓
条件式几何对齐
  ├─ 平移与尺度估计
  ├─ 难度感知路由
  └─ 对齐不确定性
          ↓
共享—特异表征
  ├─ 目标身份共享特征
  ├─ RGB/TIR 特异特征
  └─ 平台/视角条件特征
          ↓
动态融合与定位
  ├─ 正常段：局部搜索
  └─ 切换段：全局重定位
          ↓
分层时序记忆
  ├─ 初始锚点
  ├─ 短期模板
  ├─ 平台/模态原型
  └─ 质量门控长期记忆
          ↓
输出：目标框 + 置信度 + 当前状态
```

其中“状态”至少应包含：正常跟踪、模态变化、平台变化、遮挡/出视野和恢复。把这些状态显式建模，可能比让单个 Transformer 隐式学习所有情况更容易训练和解释。

## 10. 尚未解决的关键问题

### 10.1 切换事件在现实中通常未知

数据集可以提供平台标签用于分析，但部署时系统可能只收到新的视频流。模型需要在线判断：

- 是普通快速运动，还是平台切换？
- 是目标出视野，还是数据链路中断？
- 新平台中哪一个候选是原目标？

因此，DRGBT 还需要 change-point detection 与跟踪器联合建模。

### 10.2 异步、多帧率和交接空窗

现有基准经过时间对齐，较少覆盖真实系统的：

- 不同帧率；
- 时间戳漂移；
- 平台间通信延迟；
- 新旧平台观测重叠不足；
- 一段时间内所有模态都不可用。

未来可把时间戳和观测到达过程纳入任务，而不是默认规整帧序列。

### 10.3 自然未配准与真实标定漂移

程序生成的平移/缩放有利于可控实验，但真实偏差还包括深度相关视差、镜头畸变、滚动快门和时间误差。需要真实未配准、带标定信息的跨平台 RGBT 数据。

### 10.4 多目标身份与单目标协议之间存在缺口

平台交接时常出现多个同类目标，单目标框评测难以全面度量身份切换。DRGBT 与跨摄像头 MOT/ReID 之间需要更紧密的统一协议。

### 10.5 小目标与全局搜索的计算矛盾

无人机画面中的目标很小，全局高分辨率搜索成本巨大；降采样又会直接抹去目标。需要粗到细检索、目标存在性估计、区域提议或跨平台先验来减少搜索空间。

### 10.6 开放世界的任意模态/任意平台

当前主要是 RGB/TIR 与 ground/UAV 的有限组合。更一般的系统应支持新增平台或传感器而无需完全重训，包括事件相机、深度、雷达和语言描述。

### 10.7 准确率之外的部署指标

协同系统还需要报告：延迟、通信带宽、能耗、全局搜索开销、模态缺失检测错误率和不确定性校准。否则很难判断方法能否实际部署在 UAV/边缘设备上。

## 11. 值得开展的研究路线

### 11.1 近期可落地路线

#### 路线 A：CMRL + 共享—特异表征

保留 CMRL 的平台不变全局搜索，同时增加模态共享/特异分解与质量门控，解决“只学不变性导致互补信息不足”。

#### 路线 B：SCDT + 切换感知全局搜索

用 SCDT 处理完整/缺失模态，用变化点检测器触发全局搜索；重点研究切换后的时序恢复，而不是逐帧补全。

#### 路线 C：PMATrack + DRGBT

把渐进式跨模态对齐放入每个平台分支，在平台切换时重新估计对齐状态；在 Unaligned DRGBT-1K 上验证错位和平台变化的耦合。

#### 路线 D：小目标友好的粗到细重定位

利用旧平台最后可信的运动/语义信息为新平台生成候选区域，再以高分辨率局部特征验证，避免全图密集搜索。

### 11.2 更有研究价值的长期路线

- 以 belief state 建模目标身份、平台、模态质量和可见性；
- 以世界模型预测平台切换后的目标候选区域；
- 用跨平台时间重叠做自监督身份对齐；
- 面向新传感器的测试时适配，而非封闭集合分类；
- 将 SOT、ReID、跨摄像头交接和多目标数据关联统一为持续目标感知。

## 12. 推荐实验矩阵

如果要发表一篇 DRGBT 方法论文，建议至少完成：

| 实验组 | 数据 | 目的 |
|---|---|---|
| 主实验 | DRGBT-1K + DRGBT603 | 与核心 DRGBT 工作比较 |
| 动态消融 | MVO/PVO/CV | 分离模态与平台贡献 |
| 切换分析 | 前后窗口、恢复时间 | 证明真正改善交接而非普通帧 |
| 未配准 | Unaligned DRGBT-1K | 验证几何鲁棒性 |
| 跨视角预实验 | UGVT-1K | 隔离平台切换能力 |
| 缺失模态 | LasHeR-Miss/RGBT234-Miss 等 | 验证任意模态输入 |
| 属性交叉 | CV×SO/LR/SV/ARC | 检验跨平台小目标 |
| 效率 | FPS、FLOPs、显存、全局搜索开销 | 支撑部署结论 |

消融实验至少应拆开：状态检测、模态质量估计、对齐、共享/特异表示、全局搜索、模板更新和长期记忆。

## 14. 最终认识

DRGBT 不是传统 RGBT 融合的一个小变体，而是把跟踪器从稳定传感器配置推向**开放、异构、协同的观测系统**。其核心矛盾可以概括为：

$$\boxed{ \text{目标身份必须连续} \quad\text{但观测分布可以不连续} }$$

目前领域已经有了任务定义、两个基准和第一个专用方法，但仍缺少成熟的方法谱系。最有希望的下一步不是再设计一个静态双流融合模块，而是把以下能力统一起来：

1. 任意模态输入与质量估计；
2. 平台切换检测与跨视角全局重定位；
3. 未配准条件下的动态几何对齐；
4. 不变共享信息与模态/平台特异信息的平衡；
5. 防污染的分层模板记忆；
6. 面向小目标、异步通信和边缘部署的高效推理。

从研究成熟度看，这仍是一个“数据集刚成形、方法尚未充分展开”的方向，适合做有明确问题分解和评测闭环的新工作。
